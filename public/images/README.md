# Real photography goes here

Add approved photos of Seasons Café & Bakeshop to this folder (coffee, baking, the café interior, food, and
general atmosphere are the priority shots — see `PlaceholderImage` usages across `src/components` for exactly
which photo belongs where). Then swap the relevant `<PlaceholderImage />` for Next's `<Image />`, pointing at
the new file here. See the "Replacing placeholder photography" section of the root README for details.

Keep file sizes reasonable (a few hundred KB, not multiple MB) — export at the size the image is actually
displayed at, not straight from a camera or phone.
